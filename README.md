# 🔥 FREE FIRE HUB BD - #1 Diamond Top-Up & Membership Platform

FREE FIRE HUB is a modern, high-performance web platform built for Bangladeshi Free Fire gamers to instantly top-up diamonds, purchase weekly/monthly memberships, track orders live, spin lucky wheels, and participate in pro esports tournaments.

---

## 🚀 Key Features

* **Instant Diamond Top-Up:** Secure top-ups via bKash, Nagad, and Rocket with automated UID verification.
* **Live Order Tracking:** Real-time order status tracking with live delivery timelines.
* **User Dashboard:** Wallet balance, reward points, order history, and referral program.
* **Gaming Zone:** Daily Lucky Spin wheel and Free Fire trivia quiz for bonus points.
* **Pro Tournaments:** Custom room registration for Solo/Squad matches and weekly giveaways.
* **24/7 Support:** Integrated WhatsApp, Telegram, and ticketing support system.

---

## 🛠️ Tech Stack

* **Framework:** Next.js (React)
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
